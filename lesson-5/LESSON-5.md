## Чеклист

- [x] **ClickTimer** — 3 балла
    - [x] Время первого клика фиксируется через `useRef`
    - [x] Счётчик кликов хранится в `ref`, не вызывает ререндер
    - [x] В консоли — разница во времени и общее количество кликов
- [x] **PreviousInput** — 3 балла
    - [x] Текущее значение отслеживается через `onChange`
    - [x] Предыдущее значение сохраняется через `useRef`
    - [x] UI корректно отображает предыдущее значение
- [x] **FocusTracker** — 3 балла
    - [x] Установка фокуса через `ref.current.focus()`
    - [x] Переход фокуса отслеживается через `onFocus`
    - [x] Количество переходов корректно выводится в консоль
- [x] **DebouncedLogger** — 1.5 балла (бонус)
    - [x] `setTimeout` хранится в `ref`
    - [x] Старый таймер корректно очищается
    - [x] Лог появляется только по истечении задержки
- [x] **WebSocketLogger** — 1.5 балла (бонус)
    - [x] Соединение хранится в `ref`, а не в `state`
    - [x] WebSocket создаётся один раз при монтировании
    - [x] Соединение корректно закрывается в cleanup

**Итого: 12 / 12 баллов.**

## Что сделано

### Структура

```
src/
└── features/
    └── refExamples/
        ├── ClickTimer.tsx
        ├── PreviousInput.tsx
        ├── FocusTracker.tsx
        ├── DebouncedLogger.tsx
        ├── WebSocketLogger.tsx
        ├── RefExamples.module.css
        └── index.ts
```

Все компоненты — в одном слайсе `refExamples`, каждый файл решает свою задачу. Стили общие, чтобы не плодить пять почти одинаковых css-модулей.

## Проверка

```bash
npx tsc --noEmit   # без ошибок
npx eslint .       # без ошибок
npm run build      # успешно
```

UI:

- **ClickTimer** — клики не перерисовывают компонент, в консоли растёт `clickCount` и `diff`.
- **PreviousInput** — под инпутом всегда на одно значение отстаёт от текущего.
- **FocusTracker** — при клике в первое/второе поле в консоли увеличивается счётчик; кнопка фокусирует первое поле.
- **DebouncedLogger** — лог в консоли появляется только через 1 секунду после остановки ввода.
- **WebSocketLogger** — при монтировании открывается соединение, входящие сообщения логируются, при размонтировании закрывается.
